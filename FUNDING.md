# Funding PinCabOS

PinCabOS is an open-source project under active development. The project combines Linux system integration, Python and Web development, physical cabinet hardware, display and GPU configuration, audio/SSF, inputs, DOF devices, diagnostics, updates, backup/recovery workflows, and ongoing real-hardware testing.

Maintaining that scope requires developer time, test hardware, infrastructure, documentation, and release validation.

## Important distinction: credits vs. cash funding

The OpenAI programs above primarily provide product/API support. API credits can reduce development costs and accelerate code review, testing, diagnostics, documentation, release workflows, and maintainer automation, but they are not the same as unrestricted cash funding for salaries, hardware, hosting, or other operating costs.

PinCabOS may therefore pursue complementary public grants, sponsorships, and other funding sources that are compatible with the project's open-source mission.

## Planned use of development support

Support for PinCabOS would help accelerate:

- automated code review and regression testing;
- installer and update validation;
- backup, restore, and rollback safety;
- hardware compatibility diagnostics;
- WebApp and service testing;
- bilingual French/English documentation;
- multiplayer development and validation;
- release engineering and maintainer automation;
- physical cabinet test coverage.
