PINCABOS — DISTRIBUTION POLICY V3 BETA ACCESS

Règles officielles bêta:
- Garder les comptes root et pinball.
- Garder les mots de passe et accès configurés pour les bêta testeurs.
- Garder les accès WebApp/pages.
- Garder /opt/pincabos/version.json.
- Ne pas inclure le contenu de /home/pinball/Tables.
- Garder le dossier /home/pinball/Tables avec .pincabos-keep.
- Garder la structure /opt, /etc, /var, /home.
- Exclure les logs, caches, fichiers temporaires et contenu runtime.
- Ne pas supprimer les tables du système de développement.

Note:
- Les clés d'accès utilisateur comme /root/.ssh et /home/pinball/.ssh sont conservées.
- Les clés SSH host machine peuvent être régénérées au premier boot sans retirer les accès utilisateur.
