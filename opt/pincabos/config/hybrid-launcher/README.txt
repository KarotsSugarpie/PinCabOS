PinCabOS Hybrid Launcher Pilot V1
=================================

1) Pour activer le choix hybride pour UNE table, dépose un fichier
   PinCabOS-Hybrid.json dans le dossier de la table.

2) Le fichier doit contenir deux choix :
   - original
   - pup

3) Le launcher affiche l'image :
   /opt/pincabos/media/assets/PCOSGamesChoices.png

4) Contrôles :
   - Flipper gauche / Left : Original
   - Flipper droit / Right : PuP-Pack
   - Launch / Plunger / Enter / Space : confirmer

5) Le wrapper ne modifie pas les tables non configurées.
